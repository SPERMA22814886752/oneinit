OneInit
===========

```text                                          
d88D       db                        C88D 
88        o88              .dP         88 
88         88            .d8           88 
88         88           ,P             88 
88         88           00             88
```    

инициализационная система для линукс дистрибутива wilix, можно портировать на другие дистрибутивы если постаратся

===========

сборка
```bash
gcc -static -O2 -o init oneinit.c
```
